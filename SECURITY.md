# Security Policy

## Supported versions

quaternary has no releases yet. Until 1.0, only the latest commit on `main` and
the most recent release receive fixes.

## Reporting a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/oddurs/quaternary/security/advisories/new).
Do not open a public issue.

`q4` reads code files and certificates written by other people, and the
frontier accepts submissions from strangers, so reports about crashes, resource
exhaustion or a checker accepting a false certificate from crafted input are
especially welcome. A checker that accepts a false claim is treated as a
security issue, not an ordinary bug.

## What to expect

- Acknowledgement within 3 days.
- An assessment and a planned fix date within 14 days.
- Credit in the advisory and changelog, unless you prefer otherwise.
