## Ships

Ledgers for all four cells (the codetables.de GF(4) and qubit audits join the
Z4 audit and the ququart table), a public gap list built from them, and an open
way to attack it: a pull
request containing a code is refereed by CI, and an improvement produces a
record report ready to send to the table's maintainer. A logged classical
baseline search keeps the board busy. Canonical forms tell a new code from a
known one.

## Done when

- [ ] The codetables.de GF(4)-linear audit covers every entry up to the length its spike fixed.
- [ ] The gap list is generated from the ledgers and published.
- [ ] A submission pull request gets a checker verdict from CI without a maintainer touching it.
- [ ] The baseline search has produced a record report or a published negative result.

## Explicitly not in this milestone

- An LLM search layer. A volunteer client. Atlas pages.
