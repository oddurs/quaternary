## Ships

Stability, not features. The certificate format, CLI and Python API are frozen
under a written compatibility promise; install is one command on macOS, Linux
and Windows; every ledger entry replays from a clean checkout; a paper
describes the tool and its audits.

## Done when

- [ ] A certificate written by v0.1 is still accepted by v1.0's checker, enforced by CI.
- [ ] Release artefacts for every named platform come from one tagged workflow.
- [ ] The nightly replay of every ledger certificate is green.

## Explicitly not in this milestone

- Anything new. A feature found here moves to `later`.
